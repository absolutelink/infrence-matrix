# Inference Matrix — Admin Frontend

React SPA: the Inference Matrix admin UI. Built with [Vite](https://vitejs.dev/), [React](https://react.dev/), [TypeScript](https://www.typescriptlang.org/), [TanStack Query](https://tanstack.com/query), [TanStack Router](https://tanstack/router), [Tailwind CSS](https://tailwindcss.com/), and [shadcn/ui](https://ui.shadcn.com). Lint/format via [Biome](https://biomejs.dev/).

Served by the admin backend under the **`/admin`** base path (production) or by the Vite dev server (development).

## Requirements

- [Bun](https://bun.sh/)
- The admin backend running (for API access) — see `../backend/README.md`.

## Development

From the repository root:

```bash
bun install
bun run dev          # Vite at http://localhost:5173/admin/
```

`vite.config.ts` sets `base: "/admin/"` and proxies `/admin/api` and
`/v1` to `http://localhost:8000`, so run the admin backend alongside
(`cd admin/backend && uv run fastapi dev`).

## Scripts (via `bun run --filter frontend <script>`)

| Script | What |
| --- | --- |
| `dev` | Vite dev server |
| `build` | Production build → `../backend/app/frontend` |
| `lint` | Biome check (`--write`) |
| `generate-client` | Regenerate the API client from `openapi.json` |
| `test` / `test:ui` | Playwright tests |

Prefer running from the repo root: `bun run dev`, `bun run lint`.

## API client

`src/client/` is **generated** from the backend's OpenAPI schema. After any
admin route/schema change, run from the repo root:

```bash
bash ../../scripts/generate-client.sh
```

Never hand-edit files in `src/client/`.

## Routing

`src/routeTree.gen.ts` is generated by the TanStack Router plugin from the
`src/routes/` file tree — never edit by hand. If routes unexpectedly 404,
delete `src/routeTree.gen.ts` and restart the Vite server.

## Layout

```
src/
  routes/            File-based TanStack Router routes (under /admin base)
  components/        Shared UI components (shadcn/ui based)
  client/            Generated OpenAPI client (DO NOT EDIT)
  hooks/             Custom React hooks
  lib/               Utilities
  main.tsx           App entry
  routeTree.gen.ts   Generated router (DO NOT EDIT)
```
